## Bugs found
1. **Android predictive back never reaches a Cn route (G1 / §4 swipe-back rows false in a real app).** Only Flutter's `PredictiveBackPageTransitionsBuilder` registers the `WidgetsBindingObserver` that forwards `flutter/backgesture` to `TransitionRoute.handleStartBackGesture` (flutter/lib/src/material/predictive_back_page_transitions_builder.dart:117-123). `CnFadeThroughPageTransitionsBuilder.buildTransitions` (lib/src/route/cn_fade_through_page_transitions_builder.dart:57-69) and `CnPageRoute.buildTransitions` (lib/src/route/cn_page_route.dart:63-75) wrap only `_CnFadeThrough`. Repro: test/integration/interactive_back_test.dart "the system back-gesture channel scrubs the elements, {cnPageRoute,themeOverMaterial}": send startBackGesture + updateBackGestureProgress(0.5). Expected top `animation` 0.5 and siblings scrubbing; actual 1.0, nothing moves; commit falls through to `handlePopRoute` (plain 400 ms pop). The control test (same stack under PredictiveBackPageTransitionsBuilder) scrubs. The §8 handleStartBackGesture technique only proves the elements follow the route value, not that a user can drive it.
2. **iOS swipe-back is gone under the Cn route.** The Cupertino edge-drag detector lives in `CupertinoRouteTransitionMixin.buildPageTransitions` / `_CupertinoBackGestureDetector`; the fade-through builder (installed for iOS in the README/§2.4 snippet) and `CnPageRoute` (MaterialRouteTransitionMixin, own buildTransitions) never add it. Repro: same file, "iOS edge drag scrubs the elements, {cnPageRoute,themeOverMaterial}" with `platform: iOS`: drag from (5,300) by 3x100 px. Expected `userGestureInProgress` true and top `animation` < 1; actual false / 1.0. So the existing D test's iOS swipe only works because it uses the stock Cupertino builder. Fix direction (not mine): wrap the fade-through child in the platform back-gesture handling (e.g. delegate to `PredictiveBackPageTransitionsBuilder`'s observer on Android and `CupertinoRouteTransitionMixin.buildPageTransitions`'s detector on iOS), or document that the Cn route trades away interactive back.
